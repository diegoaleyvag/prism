# ADR 0003 — Static explorer over redacted artifacts

- Status: accepted
- Date: 2026‑08‑13

## Context

The results need a public, inspectable UI that can never leak secrets, never imply named‑model
performance, and never require a running server. It must link every aggregate to its
underlying cases and label everything as simulated.

## Decision

Ship a **SvelteKit + TypeScript** app exported with `@sveltejs/adapter-static` in `strict`
mode (the build fails if any route is not prerenderable). It consumes a set of **redacted JSON
artifacts** generated by the backend (`prism export`): `index`, `overview`, `families`,
`uncertainty`, `cases`, `failures`, `pareto`, `pricing`. A small `index.json` (ids + digests)
drives navigation and prerender `entries()`; larger artifacts are fetched in `load` functions
and inlined at prerender time.

Guardrails baked into the UI:

- A **mandatory `ChartFrame`** wrapper requires `title`, `denominator` and `method` and throws
  in dev if any is missing — "no chart without labels, denominator and method" is enforced,
  not reviewed. It emits `role="img"` + an accessible summary + a hidden data‑table fallback.
- A non‑dismissible **SIMULATED** banner on every page; a `ModeBadge` that never conflates
  fixture/replay/live.
- A `check:names` scan over built HTML + data rejects any provider/model name.
- Charts are hand‑rolled SVG + `d3-scale`/`d3-array` (tiny, SSR‑safe, fully labelled), so
  suppressed CIs render as an explicit "n below threshold" state rather than a fake interval.

## Consequences

- The public explorer is a bag of static files — hostable anywhere, no server, no secrets.
- Redaction + the name guard run at export time, so the artifacts are safe by construction and
  the UI just trusts them (with the `check:names` net as backstop).
- Regenerating artifacts (`prism export`) + `pnpm build` reproduces the site deterministically.

## Alternatives considered

- *Server‑rendered dashboard* — needs a runtime and risks leaking live data; rejected.
- *A charting library (Observable Plot / layerchart)* — larger bundles and weaker control over
  the mandatory denominator/method annotations and SSR; rejected in favour of small SVG + d3
  scales.
