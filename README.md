# Prism

**When is a model good enough?**

Prism is a reproducible evaluation workbench that demonstrates how an AI-system builder
defines "good enough" *by task, constraint and evidence* — not by a single leaderboard
score. It is **educational, synthetic and transparent**.

> **SIMULATED.** Every result in this release is a deterministic simulation produced by
> fixture profiles. Prism does **not** measure any named model or provider, and it never
> publishes fabricated provider results. See [`docs/LIMITATIONS.md`](docs/LIMITATIONS.md).

Full documentation, a five-minute local run, and the methodology are filled in during the
build. See [`docs/`](docs/) and [`HANDOFF.md`](HANDOFF.md).
